# Roo ZOMG recolor

The animated `panda-omg.webp` was renamed to `roo-zomg.webp` and recolored directly, as requested, on October 7, 2026. The existing `roo-omg.webp` remains a separate expression.

Neutral highlights now use warm ivory, midtones use darker gray, and the salmon blush and tongue use rosy pink. Both original frames, their 200 ms delays, infinite looping, and every alpha value are preserved. The production animation was encoded losslessly; delivery variants and still previews were regenerated through the existing quality-90 pipeline.
